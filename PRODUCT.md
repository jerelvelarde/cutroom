# Cutroom

Cutroom helps creators turn a day of photos and video into a coherent short. The primary user is a creator working on a Mac with footage on a local drive or SSD. Originals remain untouched. Google Photos can supply explicitly selected media after OAuth setup.

The main workflow is connect footage, understand the day, select a story, generate a reel, refine it through conversational feedback or timeline controls, review, and export a new version. The work surface supports repeated editing and inspection, not marketing.

Argon analyzes compact previews through Google's API and directs constrained media tools. Media processing runs locally. It is not an offline or on-device model. CopilotKit shows user-facing editorial decisions, actual tool receipts, and revisions. Storyboard HTML/CSS is generated by Argon and isolated without scripts or network access. iPhone HDR is normalized to Rec.709 before grading. ElevenLabs optionally supplies stock-voice narration with a separately configured key.

The prototype supports a selected library of up to 100 assets and reels up to 60 seconds. Google Photos and ElevenLabs integration code must not be presented as live-verified account connections until their credentials and consent are supplied. Never invent edit completion or predicted engagement. No credentials or raw private media belong in Git.
